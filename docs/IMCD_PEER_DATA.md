# IMCD peer-data review

IMCD has a narrow listed direct-peer universe.

- Azelis is a close direct peer.
- Brenntag is a close direct peer, but its H1 values in this dataset are derived from official Q1 and Q2 releases where no single H1 metric was published.
- DKSH is a broader distribution comparator and is not used as a strict margin-equivalent peer.

## Current strict classes

Adjusted EBITA margin and free-cash-flow margin have two direct peers (Azelis and Brenntag) besides IMCD.

Organic revenue growth currently has only Azelis as a clean direct H1 comparison.

Leverage has only Azelis as an aligned comparable value in this pass.

Because the peer universe is small and some definitions differ, the peer confidence was reduced from HIGH to MEDIUM and the final Fundamental Quality score remains blocked pending comparability review.
