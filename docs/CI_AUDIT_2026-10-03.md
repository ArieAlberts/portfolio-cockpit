## Policy

Do not add PostgreSQL/TimescaleDB/Redis service containers until Portfolio Cockpit has an actual persistence module that requires them. Today the repository has no database driver, broker SDK, pandas or polars dependency.

Ordinary pytest tests must stay deterministic and offline. Network access is blocked by default through tests/conftest.py.

## Monitoring hardening

The monitor now:
- supports a COCKPIT_USER_AGENT environment override so contact identity can be supplied outside the repository;
- fingerprints relevant report/result links for HTML pages instead of all visible page text;
- tracks baseline age independently from the previous monitor state;
- still cannot alter a score directly or execute an order.

The scheduled workflow still needs a repository-side COCKPIT_USER_AGENT value with a real contact address before SEC polling should be treated as production-ready.
